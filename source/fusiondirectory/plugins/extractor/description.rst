Description
===========

The Extractor plugin enables you to export data from selected users, user groups, or dynamic groups in your directory.  
You can choose which LDAP attributes to include in the export, making it easy to generate custom reports or data extracts.

Currently, the supported export format is **CSV**. Additional formats may be supported in future versions.

You can also configure email notifications to automatically send the extracted file to specified recipients after each extraction.
