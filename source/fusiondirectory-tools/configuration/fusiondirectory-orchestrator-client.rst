fusiondirectory-orchestrator-client
-----------------------------------

Configuration file
""""""""""""""""""
.. note::
	The editable file is located at **/etc/fusiondirectory-tools/fusiondirectory-orchestrator-client.conf**

[FusionDirectory Orchestrator Login]
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

.. code-block:: shell

  ORCHESTRATOR_LOGIN=="orchestrator login name"
  ORCHESTRATOR_LOGIN=="orchestrator password"


[FusionDirectory Orchestrator API]
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

.. code-block:: shell

  ORCHESTRATOR_API_URL="https://fd.fusiondirectory.org/orchestrator"
